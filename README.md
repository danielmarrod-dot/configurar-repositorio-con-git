#Pasos para crear un repositorio local vinculado a Git
1. con `cd <nombre documento>` vete al documento donde quieras el repositorio
2. con `mkdir <nombre documento>` puedes crear el documento que quieras
3. con `git init` creas el repositorio local
4. con `git remote add origin <https://github.com/danielmarrod-dot/configurar-repositorio-con-git>` enlazas el repositorio en red
5. con `git branch -M main` te pones en la rama main
6. con `git pull origin main --rebase` te descargas todo lo del repositorio para tenerlos enlazados si añadiste información antes de crearlo en local y demás
7. con `touch <nombre>` puedes crear un archivo java
8. con `git add <nombre>` puedes añadir el .java
9. con `git commit -m "<comentario>"` pones el comentario del commit que vaya a hacer
10. Por ultimo con `git push` subes todo lo que tengas al repositorio en linea
